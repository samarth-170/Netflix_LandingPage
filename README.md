# 🎬 Netflix Landing Page Clone

A responsive Netflix landing page clone built using **HTML5** and **CSS3**. This project recreates the look and feel of Netflix's homepage with a modern UI and responsive design. It was created to practice front-end development skills, including layouts, styling, and responsive web design.
---

## 🚀 Features
- Responsive design for different screen sizes
- Modern Netflix-inspired user interface
- Hero section with background image
- Navigation bar
- Feature sections
- FAQ section
- Footer with useful links
- Clean and semantic HTML structure
- Pure HTML and CSS (No JavaScript)
---

## 🛠️ Technologies Used
- HTML5
- CSS3
